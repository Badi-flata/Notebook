# تطبيق ملاحظاتي (Notebook / Notes App) 📝

تطبيق ويب لإدارة الملاحظات مبني باستخدام **React.js**. يتيح للمستخدم إنشاء الملاحظات، استعراضها، تعديلها، وحذفها مع حفظ البيانات محليًا عبر `localStorage`.

---

## 🚀 المميزات (Features)

- ➕ **إضافة ملاحظة جديدة**: إنشاء ملاحظة بعنوان ومحتوى مع التحقق من صحة المدخلات.
- 👁️ **عرض وقراءة الملاحظة**: استعراض محتوى الملاحظة المحددة بسهولة.
- ✏️ **تعديل الملاحظات**: إمكانية تعديل أي ملاحظة سابقة وتحديثها في الوقت الفعلي.
- 🗑️ **حذف الملاحظات**: حذف الملاحظات غير المرغوبة وتحديث القائمة فورياً.
- 💾 **حفظ تلقائي (Local Storage)**: بقاء الملاحظات محفوظة في المتصفح حتى بعد إعادة تحميل الصفحة.
- ⚠️ **نظام تنبيهات وتحقق**: عرض رسائل تنبيهية في حال وجود حقول فارغة تختفي تلقائياً بعد ثوانٍ.
- 📱 **تصميم متجاوب**: مناسب لمختلف أحجام الشاشات ويدعم الاتجاه العربي (RTL).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 17** (Functional Components & React Hooks: `useState`, `useEffect`)
- **CSS3** (RTL, Flexbox, Custom Scrollbars)
- **Font Awesome** (أيقونات واجهة المستخدم)
- **LocalStorage API** (تخزين البيانات محلياً)

---

## 💻 طريقة التشغيل محلياً (Getting Started)

1. **تثبيت الحزم (Dependencies):**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير (Development Server):**
   ```bash
   npm start
   ```
   سيتم فتح التطبيق تلقائياً على الرابط: [http://localhost:3000](http://localhost:3000)

3. **بناء المشروع للإنتاج (Production Build):**
   ```bash
   npm run build
   ```

4. **تشغيل الاختبارات (Run Tests):**
   ```bash
   npm test
   ```
